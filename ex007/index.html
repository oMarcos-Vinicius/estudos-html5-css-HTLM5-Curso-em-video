Aprendendo sobre semantica no HTML

Neste vídeo, o professor Gustavo Guanabara explica a importância da semântica no HTML5, diferenciando-a da estilização visual (forma).

Pontos principais abordados:

  • O que é semântica: Refere-se ao significado e ao propósito do conteúdo, e não apenas à sua aparência (01:57).
  • HTML4 vs. HTML5: Antigamente, o HTML era usado para controlar a forma (ex: tags center, font, bgcolor), o que é considerado uma prática obsoleta e incorreta no HTML5 (02:57 - 05:06).
  • Tags obsoletas: O vídeo alerta contra o uso de tags e atributos como center, font, u (sublinhado) e bgcolor, recomendando consultar o site oficial da W3C para verificar tags em desuso (05:06 - 08:12).
  • Separação de responsabilidades: O HTML5 deve focar no significado das tags (ex: usar address para endereços em vez de apenas estilizar um texto), enquanto o CSS é a ferramenta correta para definir cores, tamanhos e alinhamentos (08:12 - 11:05).
